■ HOW TO PLAY ■

Fill the grid so that every row, column, and box contains each number exactly once.

  • EASY: 4×4 grid with numbers 1-4
  • MEDIUM: 9×9 grid, ~35 clues
  • HARD: 9×9 grid, only 18 clues!

CONTROLS:

  • TAP a cell to select it
  • TAP a number to fill it in
  • HINT solves the next step
  • NOTE mode for pencil marks
  • DEL to erase a cell

KEYBOARD:

  • Arrow keys to move
  • 1-9 to enter numbers
  • Backspace to erase
  • H for hint
